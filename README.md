# Sanika Mandavgade Portfolio

## GitHub Pages upload
Upload the files in this folder directly into the ROOT of your GitHub repository.

Keep these files together:
- index.html
- style.css
- script.js
- project-1.png
- project-2.png
- project-3.png
- project-4.png
- project-5.png
- project-6.png

Do NOT upload the outer folder as a folder inside the repository.

GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root) → Save

The website uses root-relative file paths so it works when these files are uploaded directly to the repository root.
